# 考試地點
本文介紹在香港參加線下aws認證考試的地點和相關資訊。

筆者參加的兩次考試AWS Cloud Practitioner和AWS Solutions Architect Associate都是在香港的Pearson VUE考試中心參加的，地址是：

中国香港特别行政区九龙旺角彌敦道585号富時中心

考試流程：
- 如果乘坐東鐵線可以在旺角東站下車，然後步行前往考試中心。
- 考試中心位於大廈的3樓，抵達三樓後轉左，直行就可以看到考試中心。
- 考試中心的工作人員會要求你出示兩個有效的身分證件，並且簽字確認身分然後告訴你你的儲物櫃位置。
- 結束後需要拍照並且錄取指紋，然後在手機關機（不能開飛行模式）後進入考場
- 考場冷氣很強，建議帶一件外套，SAA03考試時間是130分鐘，65道題，可以選擇英文或者中文考試，如果是非英語母語者，可以申請額外的30分鐘考試時間。
- CLF考試結束後點擊結束考試填寫完畢AWS的問卷調查後會立馬顯示考試結果：PASS/FAIL，SAA考試不會顯示成績，大概八小時後可以登陸網站查看是否通過考試。
